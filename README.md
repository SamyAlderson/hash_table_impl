# hash_table_impl
A simple C hash table implementation for educational purposes.

## What it does
This is a minimalistic hash table implementation in C, designed for understanding the basics of data structures and algorithms. It includes a basic hash function, collision resolution using chaining, and basic insertion and deletion operations.

## Install
To install, simply clone this repository using `git clone`:

```bash
git clone https://github.com/SamyAlderson/hash_table_impl.git
```

## Usage
To compile and run the program, use the following commands:

```bash
make
./hash_table
```

## Building from source
To build from source, simply use the `make` command in the project root:

```bash
make
```

## Running tests
This project includes a test suite in `test/hashtable_test.c`. To run the tests, use the following command:

```bash
make test
```

## Project structure
The project consists of the following files:
- `hashtable.c`: The main hash table implementation
- `hashtable.h`: The header file for the hash table implementation
- `test/hashtable_test.c`: The test suite for the hash table implementation
